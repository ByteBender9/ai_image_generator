# 🎨 AI Image Generator

A modern and responsive web application that allows users to generate images from text prompts through a clean and interactive interface.

> **Note:** This project currently demonstrates the frontend workflow of an AI image generator. AI image generation API integration will be added in future updates.

---

## ✨ Features

- 📝 Enter custom text prompts
- 🎨 Modern and responsive user interface
- ⏳ Loading animation while generating
- 🖼️ Image preview
- ⬇️ Download generated image
- 📱 Mobile-friendly design
- 💻 Built with Vanilla JavaScript

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/ByteBender9/ai_image_generator.git
```

### Open the project

Simply open `index.html` in your preferred web browser.

---

## 📸 Preview

Enter a prompt, click **Generate Image**, and the application displays a generated image with the option to download it.
